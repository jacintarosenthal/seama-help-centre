## Dispatch checks

- Choose the view that matches the planning horizon.
- Filter by staff or job type before assuming work is missing.
- Search for the job number or customer when filters are unclear.
- Treat a booking's staff and the job header's **Assigned To** value as separate checks.
- Use selected address suggestions for sites that need map coordinates.

<Note>
  Business counts can differ between dashboard cards, job lists, report widgets and invoice tabs because they may use different statuses or date ranges. Check the view definition before reconciling a total.
</Note>
