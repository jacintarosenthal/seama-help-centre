## Before changing a record

1. Record the ID, current status, visible value and timestamp.
2. Reload the page and reproduce the issue once.
3. Check filters, date ranges, role permissions and related state dimensions.
4. For financial or integration records, verify the connected system before retrying.
5. Capture a cropped screenshot with sensitive data removed.

<Warning>
  Do not resolve a display mismatch by recreating or resending a financial record until you have checked for an existing result.
</Warning>
