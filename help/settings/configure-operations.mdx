Complete and test each applicable group before the first live job.

## Jobs and workflow

- [ ] Choose the intended default job status.
- [ ] Create plain-language job types used by scheduling and reporting.
- [ ] Create queues around real operational handling—not individual people.
- [ ] Create and test repeatable job templates.

## Finance

- [ ] Set default customer payment terms.
- [ ] Configure account codes and confirm Xero mappings.
- [ ] Create and review invoice and receipt tax rates.
- [ ] Choose approved default taxes.
- [ ] Configure markup by cost band with finance approval.

<Warning>
  **Apply Markup** is a profit-pricing control, not a document correction. It changes displayed sell values immediately. Preserve the supplier cost, understand the configured band and review the recalculated sell value before saving.
</Warning>

## Inventory

- [ ] Create stock locations with clear names.
- [ ] Confirm opening stock and reorder points.
- [ ] Test one transfer that requires receipt and one stock adjustment.
- [ ] Reconcile on hand, committed and available values.

## Communications and documents

- [ ] Test email and SMS templates with synthetic jobs and recipients.
- [ ] Use `{job_number}` rather than `{job_no}`.
- [ ] Review Quote, Work Order and Invoice document templates.
- [ ] Confirm bank details, accepted payment methods, terms and final notes.

## Result

New records inherit approved defaults, templates produce reviewed content, and the team understands every setting with financial or stock consequences.
