Settings determine what new operational and financial records inherit. Review changes with the relevant owner before applying them to live work.

<Card title="Configure core operations" icon="sliders-horizontal" href="/help/settings/configure-operations">
  Set defaults, job types, queues, payment terms, markup, accounts, tax, stock locations and templates.
</Card>

## Template types

- **Job templates** speed up recurring work. Review generated jobs because template metadata and underlying fields may not inherit as expected.
- **Email and SMS templates** use supported merge fields such as `{job_number}`.
- **Document templates** control Quote, Work Order and Invoice presentation, bank details, payment methods, terms and final notes.

<Note>
  The saved job-template library name remained independent of the edited underlying job title in testing. Review template name, description, status, type and created-job fields as separate checks.
</Note>
